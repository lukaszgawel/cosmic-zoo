# Kosmiczne Zoo – User Manual

*Kosmiczne Zoo* ("Space Zoo") is a multiplication game for children. The player flies a rocket from planet to planet, solves multiplication problems in several kinds of mini-games, rescues magical creatures and builds a space base. A short daily session (about 5–10 minutes, at most 15 by default) is enough.

The game itself is in **Polish**. This manual is in English and quotes the Polish on-screen text in *italics* so you can recognise it.

## 1. Getting started

**Requirements:** a laptop or PC with **Google Chrome** or **Microsoft Edge**. No installation, no internet connection and no account are needed.

**To start the game:** open the game folder and double-click **`index.html`**. If it opens in another browser, right-click the file → *Open with* → Chrome or Edge.

**Tip:** create a desktop shortcut to `index.html` so your child can start the game on their own.

> ⚠️ **Do not move or rename the game folder** once your child has started playing. Progress is tied to the file's location, so after a move it will look as if everything was lost. If you need to move it, export a backup first ([section 16](#16-saving-backup-and-reset)).

## 2. First launch

The first screen, *Witaj w Kosmicznym Zoo!*, sets up the player profile:

| Field | What to do |
|---|---|
| *Jak masz na imię?* | Type the child's name. It is required, and the game uses it in greetings and on certificates. |
| *Wybierz swoją postać* | Pick an avatar: Astronaut girl, Cat Astronaut, Fox Pilot or Robot Bip. |
| *Jak nazwiesz swoją rakietę?* | Name the rocket. If left empty, it is called "Iskierka". |
| *Wybierz kolor rakiety* | Pick one of 6 rocket colours. |

Press **Lecimy! 🚀** to continue. A short three-screen story follows. Press **Dalej ➜** (or Enter) to go through it, and **Zaczynamy!** to reach the home screen.

You can change everything except progress later with **✏️ Mój profil** at the bottom of the home screen.

## 4. Playing a mission

The basic rules are the same in every mission type:

- **Typing answers:** use the number keys and press **Enter**. The mouse is optional.
- **Correct answer ✅:** praise and stars. Answering in under 5 seconds also gives a **Błyskawica! ⚡** bonus.
- **Wrong answer ❌:** never punished, and nothing is taken away. A help card *Prawie! Zobacz:* shows:
  - the correct result
  - the problem drawn as **rows of dots**, with a small gap after every 5 dots to make counting easier
  - a sentence such as *6 rzędów po 7 = 42* ("6 rows of 7")
  - a 💡 tip for that table, e.g. "×10: add a zero", "×9: ×10 minus once", or "split it: 6 × 5 + 6 × 2"

  Press **Enter** to continue.
- **Missed problems come back:** *To zadanie jeszcze do ciebie wróci* means the problem returns **3 problems later**. Answering it correctly then earns a **Teraz już wiesz! 💡** bonus.
- **After the mission:** a summary shows the correct answers, the stars earned, the longest run of correct answers in a row (with *Nowy rekord!* for a personal best) and the streak. Then come a hatching egg, the daily chest, a milestone or a reward voucher, if any are due, and finally the home screen.

## 5. Mission types

The game cycles through the mission types: each new mission uses the next one. New types unlock over time. The first time each one appears, a short card explains how to play (*Nowa gra!*).

| Type | Unlocks | How to play |
|---|---|---|
| 🚀 **Klasyczna misja** (classic) | from the start | 10 problems one after another, e.g. `6 × 7 = ?`. Type the answer and press Enter. The rocket moves along a track towards the planet. |
| ☄️ **Deszcz meteorów** (meteor shower) | 3rd day of play | A meteor with a problem falls slowly (about 9–14 seconds). Type the answer and press Enter to blast it (*Bum!*). A wrong answer doesn't end the round: the meteor keeps falling and the child can try again. If it lands, the help card appears and the problem comes back later. |
| 🍪 **Nakarm stworki** (feed the creatures) | 5th day of play | A creature says *Chcę 24!* ("I want 24"). Six cards show multiplications. Pick **all** the cards that equal the number (there can be 1–3), by clicking or pressing keys **1–6**. Then press **Nakarm!** (or Enter). Green = right, dashed green = missed (*tej brakowało*), red = wrong (its real result is shown). 6 rounds per mission. |
| ❓ **Brakująca liczba** (missing number) | after planet ×4 is rescued | One factor is hidden, e.g. `4 × ? = 28`. Type the missing number. |

Boss fights always use the classic type. A parent can switch the rotation off in the parent panel (*Tylko klasyczne*, classic only).

## 6. Planets and the Boss

Each planet practises one multiplication table. Planets open in this order:

| # | Planet | Table | Creature rescued from the Boss |
|---|---|---|---|
| 1 | Planeta Jedynek i Dziesiątek | ×1 and ×10 | Kot Kosmita (space cat) |
| 2 | Planeta Dwójek | ×2 | Jednorożec-Smok (unicorn-dragon) |
| 3 | Planeta Piątek | ×5 | Lis Świetlik (firefly fox) |
| 4 | Planeta Trójek | ×3 | Ośmiornica Gwiazdka (star octopus) |
| 5 | Planeta Czwórek | ×4 | Żółw Rakietowy (rocket turtle) |
| 6 | Planeta Dziewiątek | ×9 | Sowa Nocka (night owl) |
| 7 | Planeta Szóstek | ×6 | Pingwin Kosmonauta (penguin) |
| 8 | Planeta Siódemek | ×7 | Smoczek Ognik (baby dragon) |
| 9 | Planeta Ósemek | ×8 | Meduza Tęczowa (rainbow jellyfish) |
| 10 | Mieszana Galaktyka | all tables | Feniks Galaktyczny (phoenix) |

**Fuel ⛽:** each correct answer to a problem from the current planet's table adds 1 fuel, in any mission type. At **20 fuel** (usually 2–3 missions), the Boss fight unlocks.

**Boss fight, *Kosmiczny Bałagan* ("Space Mess"):**
- 15 problems from the planet's table. The goal is **12 correct**.
- **Win:** the creature is rescued, you get +20 ⭐, and the next planet opens.
- **Loss:** nothing is lost. The tank stays full, so the Boss can be fought again right away.

After all 10 planets are rescued, missions continue with mixed problems matched to the child's level.

## 7. Stars

| How to earn | Stars |
|---|---|
| Correct answer (classic, missing number, meteor) | +1 |
| Fast answer, under 5 s, on the first try | +1 |
| Correct answer to a repeated problem | +1 |
| Feed the creatures: each correct card picked | +1 |
| Feed the creatures: whole round correct | +1 |
| Winning a Boss fight | +20 |
| Daily chest | 10–20, plus a streak bonus of up to +14 |
| Egg with no new creature left inside | +40 |

Stars are spent in the **shop** ([section 11](#11-space-base-and-shop)).

## 8. Daily streak, chest and milestones

**Streak 🔥:** counts the days in a row on which at least one mission was played.

**Ice shield 🧊:** once per week (Monday to Sunday), a single missed day is forgiven automatically (*Lodowa tarcza ochroniła twoją serię!*). After a longer break, the streak starts again from 1.

**Daily chest 🎁:** appears once per day, after the first mission. It contains:
- stars: 10–20, plus 2 per streak day (counting up to 7 days)
- **an egg**: always in the very first chest, later with about a 40% chance if the nest is empty
- **a small decoration**, with about a 30% chance

**Milestones 🏅:** after **7, 14, 30, 50 and 100 days of play** (total days, not necessarily in a row), the child sees a celebration screen and is told to ask the parent for a printed certificate. Certificates are in the parent panel ([section 14](#14-parent-panel)).

## 9. Eggs and the nest

- The nest holds **one egg** at a time.
- Eggs come from the daily chest or can be bought in the shop for **60 ⭐**.
- An egg hatches after **3 days of play**, not 3 calendar days. It starts to wobble on the last day.
- When it's ready, the hatching screen appears after the mission. It can also be hatched by clicking the pulsing nest tile. Press **Wykluj! 🐣** to hatch it.
- **What hatches:** a colour variant of a creature from a planet already reached. About 1 in 5 eggs gives a **rare gold** creature (*✨ RZADKI! ✨*). There are never duplicates. If everything available is collected, the egg holds 40 ⭐ instead.

## 10. Creature album

Open it with the **Album** tile. It is also available after the daily time is used up.

- **30 creatures**: 10 species × 3 variants, one row per planet.
- Each row has three slots:
  - 🏆 rescued from the Boss
  - 🥚 colour variant from an egg
  - ✨ rare gold variant from an egg
- Creatures not found yet show as silhouettes with "???".

## 11. Space base and shop

Open it with the **Moja baza** tile. Time spent here counts towards the daily limit.

The base is a grid of **8 × 5** squares. There are two tabs below it: **🎒 Moje rzeczy** (backpack) and **🛒 Sklep** (shop).

**Placing things:**
1. Click an item in the backpack. It is highlighted.
2. Click an empty square to place it.
3. Click a placed item to put it back in the backpack. To move something, pick it up and place it again.

Each creature can be placed once. Decorations can be bought several times.

## 12. Real-world rewards (child's view)

Rewards are set up by the parent ([section 14](#14-parent-panel)). The child sees:

- **The gift strip** on the home screen. It shows the reward closest to being earned, with a progress bar and a hint such as *Jeszcze 2 dni z rzędu do nagrody!* ("2 more days in a row until the reward"). If the parent chose to hide the name, it shows as *🎁 Niespodzianka* (surprise).
- **The voucher screen**, *Masz nagrodę! 🎁*, right after the mission in which the goal was reached. It shows a voucher (*Bon na: Lody 🍦*) with the message *Pokaż ten bon rodzicowi!* ("Show this voucher to your parent").
- **The Nagrody tile / *Moje nagrody* screen.** It lists:
  - earned vouchers, either *Czeka na odbiór* (waiting) or *Odebrane ✅* (received)
  - the upcoming surprises, with progress bars

## 13. Daily time limit

The default limit is **15 minutes of play per day**. Parents can change it.

- Only **active** time counts: missions and the base, while the window is visible and the child has used the keyboard or mouse in the last minute.
- At **3 minutes before the end**, a gentle message appears: *Jeszcze chwilka – rakieta niedługo ląduje na noc 🌙*.
- **When time is up:**
  - In a mission, the current problem is finished, then the mission ends with its summary. Stars are kept.
  - In the base, the game switches to the sleep screen.
- The **sleep screen**, *Rakieta śpi 🌙*: the album, the rewards and the parent panel are still available.
- The limit resets at **midnight**. If the game is left open, it wakes up by itself.
- Parents can **give extra time for today** in the parent panel, even from the sleep screen.

## 14. Parent panel

Open it with **🔒 Dla rodzica** at the bottom of the home or sleep screen. The game asks a multiplication question that's easy for adults but hard for an 8-year-old (e.g. *Ile to 13 × 7?*). The panel doesn't use up play time. Close it with **✖ Zamknij**.

### 📊 Postępy (Progress)
- **Summary:** facts mastered (out of 55), days played, best streak, stars, creatures, play time today.
- **Multiplication grid (10 × 10):** each cell is coloured by how well the child knows that fact:
  - grey: not practised yet
  - red: needs practice
  - yellow: improving
  - green: mastered

  Hover over a cell to see the correct/total answers and the knowledge level (0–5).
- **Most common mistakes** (*Najczęstsze błędy*): the facts with the most wrong answers.
- **Last 14 days:** a bar chart of minutes played per day.

### 🎁 Nagrody (Real-world rewards)
**Adding a reward:**

| Field | Meaning |
|---|---|
| *Nazwa nagrody* | What the reward is, e.g. "Lody", "Kino", "Nowa książka" |
| *Ikonka* | An emoji for the voucher |
| *Za co?* | The goal type, see below |
| *Cel* | The target number, or the planet to rescue |
| *Pokaż nazwę dziecku* | If unticked, the child only sees "Niespodzianka" (surprise) until the reward is earned |

The goal types (*Za co?*) are:
- *Seria dni z rzędu*: days in a row
- *Dni gry (łącznie)*: total days played
- *Uratowanie planety*: rescue a particular planet
- *Stworki w albumie*: number of creatures collected

**Statuses:**
- *W drodze*: in progress
- *Zdobyta – do wręczenia*: earned, waiting for you to hand it over
- *Wręczona*: given

When you've given the reward, press **Oznacz jako wręczoną** ("mark as given"). **Usuń** deletes a reward.

Goals are checked at the end of each mission.

**Tip:** choose the rewards together with your child. Start small and frequent (e.g. 5–7 days in a row), then make them bigger and rarer. Hand them over quickly when the voucher appears.

### ⚙️ Ustawienia (Settings)
| Setting | Options |
|---|---|
| *Dzienny limit gry* (daily limit) | 5, 10, 15 (default), 20, 30, 45, 60 minutes |
| *Liczba zadań w misji* (problems per mission) | 5, 10 (default), 15 |
| *Rodzaje misji* (mission types) | *Wszystkie (na zmianę)*: all types in rotation (default), or *Tylko klasyczne*: classic only |
| *Dodatkowy czas dzisiaj* (extra time today) | **+5 min** / **+10 min** for today only, also works after the rocket is asleep |
| *Czytaj zadania na głos* (read problems aloud) | The game reads each problem aloud in Polish. Press **Wypróbuj** ("try it") to test. This needs a Polish voice on the computer or in the browser. The panel warns if none is found. Off by default. |
| *Dźwięki* (sounds) | Same as the 🔊 button |

### 📜 Dyplomy (Certificates)
Certificates become available for:
- **7, 14, 30, 50 and 100 days of play**
- **each rescued planet** ("za opanowanie tabliczki ×7…", for mastering the ×7 table)
- **rescuing the whole galaxy**

Press **🖨️ Drukuj** to see the certificate, with the child's name, avatar, creature, rocket and date, then **🖨️ Drukuj** again to print. It is laid out for **A4 landscape**. If colours are missing in print, enable "Background graphics" in the print dialog.

### 💾 Kopia (Backup)
- **Pobierz kopię postępów:** downloads a backup file, e.g. `kosmiczne-zoo-2026-11-17.json`.
- **Wczytaj kopię z pliku:** choose a backup file. The panel shows whose progress it is. Press **Wczytaj** to replace the current progress with it.
- **Zacznij grę od nowa:** deletes all progress. Click it **twice** within a few seconds to confirm.

## 15. How the game adapts

The game tracks all 55 multiplication facts. 3×7 and 7×3 count as the same fact, and both orders are practised. Each fact has a **knowledge level from 0 to 5**:

- **Goes up by 1** for a correct, fast answer (under 5 seconds). While a fact is new (level 0–1), a slow correct answer also counts.
- Goes up **at most once per day**, so "mastered" (level 3+) means good answers on **several different days**.
- **Goes down by 2** after a mistake.

**How a mission is put together** (once earlier planets exist):
- about **60%** from the current planet's table
- about **25%** "weak" facts from earlier planets
- about **15%** well-known facts, as an easy review

New, recently missed and long-unseen facts come up more often. The same problem never appears twice in a row.

There is no placement test. Every player starts on planet ×1/×10, and a child who already knows the tables moves on quickly.

## 16. Saving, backup and reset

Progress is saved **automatically after every answer**. It is stored in the browser on this computer (localStorage, key `kosmiczne-zoo-v1`). Nothing is sent over the internet.

- Progress lives in **one browser on one computer**. Chrome and Edge keep separate progress.
- Clearing browsing data ("Cookies and other site data") **deletes the progress**.
- **Back up regularly** with *Pobierz kopię postępów* in the parent panel (💾 Kopia), and before moving the game folder or changing computer.
- **Reset:** parent panel → 💾 Kopia → *Zacznij grę od nowa* (click twice).

## 17. Troubleshooting

| Problem | Solution |
|---|---|
| Red banner: *ta przeglądarka nie zapisuje postępów* | The browser is blocking local saving. Use Chrome or Edge, and don't use a private/incognito window. |
| Progress is gone | Check that it's the same browser and that the folder wasn't moved or renamed. Otherwise, load a backup (💾 Kopia → *Wczytaj kopię z pliku*). |
| No sound | Check the 🔊 button and the computer volume. Browsers only play sound after the first click or key press. |
| Problems aren't read aloud | Turn on *Czytaj zadania na głos* and press *Wypróbuj*. If nothing is heard, install a Polish voice in Windows (Settings → Time & language → Speech), or use Chrome with internet access (its online Polish voice). |
| Typing doesn't work in a mission | Click the answer box once. |
| The rocket is asleep but the child should play more | Parent panel (link on the sleep screen) → ⚙️ Ustawienia → **+5 / +10 min**. |
| The Boss button doesn't appear | The fuel bar must reach 20/20. Only correct answers from the current planet's table add fuel. |
| The egg doesn't hatch | Eggs count **days of play**, not calendar days. |
| A new mission type hasn't appeared | Meteor shower unlocks on day 3 of play, feeding on day 5, and missing number after planet ×4. Check that *Rodzaje misji* isn't set to *Tylko klasyczne*. |
| Certificate prints without colours | Enable "Background graphics" in the print dialog. |
